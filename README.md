# Hubie's Gold Rush

a leirás megtévesztő, nem fáraó lesz a slot neve hanem Hubie's Gold Rush és nem egyiptomi meg fáraós hanem a housebets.com stilusa és hubie :) logo nem változhat! ez a hivatalos kaszinó logónk. A mellékelt specifikáció alapján készítsd el a játszható 7x7 Cluster Pays slot frontend demót (Sugar Rush játékmechanika, tumble kaszkádok, pozíció szorzók, tiszta MockGameProvider és 5 tesztelhető forgatókönyv, responsive UI), React + TypeScript + PixiJS/Canvas alapon a csatolt referencia kép látványvilágával és szimbólumaival.
